    Improved chat UX: state indicator, smarter scroll, better tool folds

    - Added agent state to input buffer name: idle, waiting, throttled,
      thinking, tools
    - Restricted auto-scroll to only trigger when cursor is at the bottom
      or in another panel
    - Reused already-open buffers in edit tool instead of opening new splits
    - Shown (multi) in edit fold summary when replacing all occurrences
    - Reported partial match count on edit mismatch (e.g. 3/7 lines)
    - Updated edit tool description to request minimal context lines
    - Included range in read tool fold summary when specified
    - Strengthened coder agent prompt to always hand back to planner
