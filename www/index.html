terminal client for the tai agent. the neovim
plugin is tai.nvim.

one posix shell script. jq and curl do the json
and http. it reads .tai from the project
(the same file as the plugin) and keeps its own
session at .tai-cli-session.json. the jq
filters and prompts are read from
$XDG_DATA_HOME/tai (default
~/.local/share/tai), then from each directory
in $XDG_DATA_DIRS.


screen

output is appended to the terminal. scroll the
window to read earlier lines. the input is the
> line. the terminal title tracks the status
line. the bell rings when the agent stops.

tai  llama_cpp/gemma  orchestrator  [idle]
you: fix the build
CODER show the error [1]
>

an empty prompt shows ctrl-h help in dim text.
that text is not part of the line.


keys

enter      send the line. y / n / s while a
           command is waiting
ctrl-c     stop the agent
ctrl-l     redraw the prompt
ctrl-u     clear the line
ctrl-n     clear the session
ctrl-h     show or hide help
ctrl-q     quit


install

make test
make install

make install puts the script in ~/.local/bin
and the data files in ~/.local/share/tai
($(PREFIX)/share/tai when PREFIX is set).
a PREFIX of /usr/local or /usr is found
through the default XDG_DATA_DIRS.
