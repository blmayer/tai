    Reworked agent handoff mechanism and improved edit tool

    - Converted the internal agent calling from the fragile coder_call variable and direct output injection to proper 'coder' and 'planner' tools. Each agent now keeps its own independent conversation history.
    - Handoffs are performed by emitting a tool call that immediately returns a short acknowledgement ("coder is working on the task.") and then switches to the target agent.
    - Merged the near-duplicate task() and code() methods into a single continue() implementation.
    - Made the context token count shown in the input buffer name derive from the last message that carries token_usage in the currently active agent's history instead of a global last_ctx.
    - Fixed the edit tool's block matching. The old streaming matcher would latch onto the first occurrence of the opening line of old_text and fail (or edit the wrong region) if the full block did not follow. It now uses an exhaustive sliding-window search over whitespace-normalized lines so later valid alignments for the complete old_text are considered.
    - Added a 'multi' boolean parameter to the edit tool. When true, every matching occurrence of the supplied block is replaced (replacements are applied from the bottom of the file upward).
    - Added lua/tai/tests/edit_test.lua with dedicated coverage for the repeated-first-line case, multi replacement (including with whitespace differences), single vs multi semantics, prepend behaviour, and no-match errors.
